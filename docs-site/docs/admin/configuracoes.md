# Configurações Gerais

Acesse **Configurações** no menu lateral para gerenciar todos os aspectos da sua conta.

## Seções disponíveis

| Seção | O que configura |
|-------|----------------|
| **Funis** | Criar e organizar funis e etapas do pipeline |
| **Campos Personalizados** | Adicionar campos extras ao cadastro de oportunidades |
| **Integrações** | Webhooks para receber leads externos |
| **Alertas** | Regras de notificação automática |
| **Usuários** | Convidar e gerenciar membros da equipe |
| **Dados da Empresa** | Nome, logo e informações do tenant |
