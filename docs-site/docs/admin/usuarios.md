# Gestão de Usuários

Gerencie quem tem acesso à sua conta Boostly em **Configurações → Usuários**.

## Convidando um usuário

1. Clique em **Convidar Usuário**
2. Informe o e-mail
3. O usuário receberá um link de acesso por e-mail

## Papéis

| Papel | Permissões |
|-------|-----------|
| Administrador | Acesso total, incluindo configurações |
| Usuário | Acesso operacional (Pipeline, Projetos, Tarefas) |

## Removendo um usuário

Clique nos três pontos ao lado do usuário e selecione **Remover**. O usuário perde acesso imediatamente.
