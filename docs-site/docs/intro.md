# O que é o Boostly?

O **Boostly** é uma plataforma de gestão de canais de vendas white-label, desenvolvida para ISVs (Independent Software Vendors) que precisam oferecer um CRM completo aos seus clientes sem construir do zero.

## O que você pode fazer

- **Pipeline visual** — gerencie oportunidades em funis kanban customizáveis
- **Integrações via webhook** — receba leads de qualquer fonte externa automaticamente
- **Alertas automáticos** — crie regras para ser notificado quando algo precisa de atenção
- **Gestão de equipe** — controle de usuários e permissões por tenant
- **Projetos e tarefas** — acompanhe projetos e atribuição de tarefas à equipe

## Como está organizado

O Boostly é multi-filial: cada ISV pode ter múltiplas filiais com dados completamente isolados. Usuários, permissões e configurações são independentes por filial.
