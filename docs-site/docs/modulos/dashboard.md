# Dashboard


---

## O que é

Painel visual e personalizável com indicadores de desempenho do canal. Cada usuário pode montar seu próprio layout com os KPIs que considera mais relevantes.

---

## Quem acessa

Todos os papéis — cada um vê dados limitados pela sua filial e permissões.

---

## O que mostra

Grade de widgets configuráveis organizados em seções. Cada widget exibe um indicador com valor atual, variação e barra de progresso em relação à meta.

---

## Como usar

### Personalizar o dashboard

1. Clique em **Editar layout**
2. Crie seções e defina os quadrantes
3. Clique em **+** em um quadrante vazio para inserir um indicador
4. Busque o indicador pelo nome e selecione
5. Configure título, período e meta (opcional)
6. Salve o layout

### Filtrar período

Use o seletor de período global no topo para filtrar todos os widgets de uma vez. Widgets com período local configurado ignoram o filtro global.

### Remover indicador

Clique no ícone de remoção no canto do widget → confirma.

---

## Regras de negócio

- O layout é salvo por usuário — cada pessoa tem seu próprio dashboard
- Widgets configurados com **período local** não são afetados pelo filtro global
- Indicadores disponíveis são os cadastrados em `/settings/indicadores`
