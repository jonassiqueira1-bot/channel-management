# Funis

Funis representam os diferentes processos comerciais da sua empresa. Você pode ter múltiplos funis (ex: "Vendas", "Pós-venda", "Renovação").

## Criando um funil

1. Vá em **Configurações → Funis**
2. Clique em **Novo Funil**
3. Adicione as etapas em ordem (cada etapa representa uma fase do processo)
4. Salve

## Definindo o funil padrão

O funil padrão é usado quando uma oportunidade é criada sem funil definido (ex: via webhook). Configure-o em **Configurações → Funis**.

:::info
Toda oportunidade deve pertencer a um funil. O sistema não permite oportunidades sem funil associado.
:::
