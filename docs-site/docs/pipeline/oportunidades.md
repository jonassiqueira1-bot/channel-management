# Oportunidades

Uma oportunidade representa um negócio em andamento com um cliente ou lead.

## Campos disponíveis

| Campo | Descrição |
|-------|-----------|
| Título | Nome do negócio ou lead |
| Empresa | Empresa do contato |
| Contato | Nome, e-mail e telefone |
| Valor | Valor total da oportunidade |
| Valor CDU / SMS / Serviço / Desconto | Detalhamento financeiro |
| Origem | Fonte do lead (ex: "Site", "Webhook RD Station") |
| Responsável | Usuário responsável pelo negócio |
| Prazo | Data limite |
| Situação | Em negociação / Ganho / Perdido |
| Descrição | Anotações livres |

## Editando uma oportunidade

Clique no card no Pipeline para abrir o formulário completo. As alterações são salvas ao clicar em **Salvar**.
