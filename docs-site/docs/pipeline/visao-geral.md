# Pipeline de Vendas

O Pipeline é o coração do Boostly. Ele exibe suas oportunidades em formato **Kanban**, organizadas por funil e etapa.

## Navegando entre funis

Use o seletor no topo da página para alternar entre funis. Cada funil tem suas próprias etapas e oportunidades.

## Filtrando oportunidades

Clique no ícone de filtro para filtrar por:
- Responsável
- Campanha
- Situação (em negociação, ganho, perdido)
- Período

## Movendo oportunidades

Arraste e solte o card entre as colunas para atualizar a etapa. A mudança é salva automaticamente.
