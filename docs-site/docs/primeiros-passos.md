# Primeiros Passos

## Acessando a plataforma

Acesse [boostly.com.br](https://boostly.com.br) e faça login com as credenciais fornecidas pelo seu administrador.

## Configurando o primeiro funil

1. Vá em **Configurações → Funis**
2. Clique em **Novo Funil**
3. Dê um nome (ex: "Vendas") e adicione as etapas do seu processo comercial
4. Salve — o funil aparecerá no Pipeline imediatamente

## Criando a primeira oportunidade

1. Acesse **Pipeline** no menu lateral
2. Clique em **+ Nova Oportunidade**
3. Preencha título, valor e selecione o funil
4. Arraste o card entre as etapas conforme o negócio avança
