# Login

**Acesso:** Público (sem autenticação)

---

## O que é

Tela de entrada da plataforma. Permite que qualquer usuário convidado acesse o sistema com suas credenciais.

---

## Quem acessa

Qualquer pessoa com cadastro ativo na plataforma.

---

## O que mostra

Formulário de acesso com campos de e-mail e senha, link para recuperação de senha e logotipo da empresa.

---

## Como usar

### Entrar na plataforma

1. Acesse `https://www.boostly.com.br/login`
2. Informe o **e-mail** cadastrado
3. Informe a **senha**
4. Clique em **Entrar**
5. Você será redirecionado para o Dashboard ou para a tela inicial do seu perfil

### Esqueci minha senha

Clique em **Esqueci minha senha** abaixo do botão Entrar → você será redirecionado para a tela de recuperação de senha.

---

## Regras de negócio

- Usuários com conta inativa recebem mensagem de acesso bloqueado e devem contatar o administrador
- Após tentativas inválidas consecutivas, o acesso pode ser temporariamente bloqueado por segurança
- Ao fazer login, o sistema identifica a filial do usuário e carrega os dados correspondentes
