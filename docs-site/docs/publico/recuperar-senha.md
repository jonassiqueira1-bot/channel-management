# Recuperar Senha

**Acesso:** Público (sem autenticação)

---

## O que é

Fluxo de redefinição de senha para usuários que esqueceram suas credenciais.

---

## Quem acessa

Qualquer usuário com conta ativa na plataforma.

---

## O que mostra

Formulário com campo de e-mail para solicitação de redefinição.

---

## Como usar

### Solicitar redefinição

1. Informe o e-mail cadastrado
2. Clique em **Enviar instruções**
3. Verifique sua caixa de entrada — você receberá um e-mail com o link para redefinir a senha
4. Clique no link recebido → você será redirecionado para criar uma nova senha
5. Informe e confirme a nova senha → clique em **Salvar**
6. Após salvar, você será redirecionado para o Login

---

## Regras de negócio

- O link de redefinição expira em 1 hora por segurança — solicite um novo se necessário
- Se não receber o e-mail em alguns minutos, verifique a pasta de spam
- Caso o e-mail informado não esteja cadastrado, nenhum e-mail é enviado (por segurança, a mensagem na tela é a mesma)
