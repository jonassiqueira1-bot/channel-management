Perguntas comuns

Preciso de cartão de crédito para criar conta?

Não. Você cria a conta gratuitamente e explora a plataforma sem informar dados de pagamento. O cartão só é necessário ao assinar um plano pago.

O que é uma filial?

Uma filial representa uma unidade de negócio com dados completamente isolados — usuários, pipeline, parceiros e configurações independentes. Ideal para empresas que operam em múltiplas regiões ou marcas.

Posso mudar de plano depois?

Sim, a qualquer momento. O upgrade é imediato e o downgrade entra em vigor no próximo ciclo de cobrança. Nenhum dado é perdido na mudança.

Como funciona a integração com sistemas externos?

Via webhook — qualquer sistema que envie eventos HTTP pode alimentar o Boostly. O mapeamento de campos é feito sem código, diretamente pelo painel de Integrações.

Meus dados ficam seguros?

Sim. Cada conta tem isolamento completo de dados. Todos os acessos são autenticados e registrados em log de auditoria com retenção de 12 meses.
